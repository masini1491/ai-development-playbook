# External References

This directory stores bounded external sources used only for Playbook maintainer comparison and self-review.

Each dossier should preserve at minimum:

- source / repository;
- immutable revision when available;
- license / provenance where relevant;
- authority boundary;
- relevant observations;
- limitations / do-not-assume;
- reference adoption state (`ADOPTED`, `ADAPTED`, `REFERENCE-ONLY`, or `REJECTED` only when justified by current canonical governance);
- revisit trigger when useful.

A dossier is not capability evidence for normal Playbook discovery. It remains maintainer evidence until a conclusion is promoted through normal governance.
