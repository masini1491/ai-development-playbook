# Development Candidates

This directory stores possible Playbook development directions that are worth remembering for maintainer review but are not yet admitted work.

A candidate should state:

- hypothesis / possible capability;
- why it may matter;
- current evidence and uncertainty;
- what evidence would change the decision;
- current obligation (`NONE` unless normal governance separately admits work).

Presence here does not create a Hot/Cold task, execution authority, or capability claim. Promote only through the normal work-admission and canonical-update gates.
